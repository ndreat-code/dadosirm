# DADO CRM — regole di progetto

## Font
- **Mai font monospace** (`font-mono`, `monospace`, JetBrains Mono, Space Mono, ecc.) salvo richiesta esplicita dell'utente.
- Font standard: **Switzer** (`font-sans` / `font-switzer`). In `tailwind.config.js` la classe `font-mono` è già un alias di Switzer: non reintrodurre un vero monospace.
- Font decorativi scelti dall'utente (Sixtyfour, Major Mono Display, Press Start 2P, ecc.) restano solo dove già presenti.
